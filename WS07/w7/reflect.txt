***for the sortBakery function, would anything differ in how it is implemented if the choice of collection was either a vector or a list? If there is a difference what is it?
vector provides random access iterators so we can use std::sort directly. Implementation as follows: 
std::sort(m_collection.begin(), m_collection.end(), [](const BakedGood& b1, const BakedGood& b2) {
	return b1.description < b2.description;
});

list is list class template defines classes that manage doubly linked sequences that are optimized for insertion and removal of elements anywhere throughout the list, particularly in larger sequences. list provides bidirectional iterators, not random access iterators, so we cannot use std::sort directly. Instead, list has a sort method to work with linked lists. The implementation will be as following if the m_collection is a list:
m_collection.sort([](const BakedGood& a, const BakedGood& b) {
            return a.stock < b.stock;
        });
