///was there any benefit from using binary files in this workshop?
	One big advantage of using binary files is that it's generally faster to read from and write to compared to text files because they do not require conversion of data from binary to text and vice versa. The data is stored in the same format as it is in memory, so there is no overhead of formatting.
	Using binary files can also ensure precision because when storing numerical data, as in this workshop, binary files preserve the exact binary representation of the data, ensuring that no precision is lost.
